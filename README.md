# Farm2Family

Farm2Family is a full-stack web application that connects farmers directly with customers. It enables farmers to create and manage vegetable baskets, while customers can browse, subscribe, and order fresh farm produce.

## Features

### Farmer
- Farmer Registration & Login
- JWT Authentication
- Farmer Dashboard
- Add Vegetable Packets
- Edit/Delete Packets
- View Orders
- Earnings Dashboard

### Customer
- Customer Registration & Login
- Customer Dashboard
- Browse Vegetable Baskets
- Place Orders
- Order History
- Profile Management

## 🛠 Tech Stack

### Frontend
- Next.js
- React.js
- TypeScript
- CSS

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Authentication

- bcrypt

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/farm2family.git
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd f2f
npm install
npm run dev
```
